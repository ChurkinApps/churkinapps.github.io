Сторонние компоненты в приложении LightSchool для Android
← LightSchool Политика конфиденциальности Сторонние компоненты English Русский

Дата обновления: 25 сентября 2026 г.

В LightSchool для Android использованы перечисленные ниже программы вместе с библиотеками, от которых они сами зависят. Каждая используется на условиях своей лицензии. Если компонент есть только в одной версии приложения, это указано; в версии из RuStore нет Google Play Billing и обновлений через Google Play.

По лицензии Apache 2.0 (текст лицензии)

  • Kotlin, kotlinx.coroutines, kotlinx.serialization (JetBrains): github.com/JetBrains/kotlin
  • Библиотеки AndroidX (Jetpack): Core, AppCompat, Activity, Fragment, Lifecycle, Navigation, Room, SQLite, DataStore, WorkManager, Glance, SplashScreen, Window и другие: developer.android.com/jetpack/androidx
  • Jetpack Compose, Material 3 и Material Icons: developer.android.com/jetpack/compose
  • Среда выполнения Compose Multiplatform (JetBrains): github.com/JetBrains/compose-multiplatform
  • Material Components for Android: github.com/material-components/material-components-android
  • Dagger и Hilt, javax.inject, jakarta.inject: github.com/google/dagger
  • Retrofit, OkHttp, Okio (Square): square.github.io/retrofit, square.github.io/okhttp
  • Gson: github.com/google/gson
  • Guava, аннотации Error Prone, JSR 305 и JSpecify: github.com/google/guava
  • ZXing и ZXing Android Embedded: github.com/zxing/zxing, github.com/journeyapps/zxing-android-embedded
  • Reorderable: github.com/Calvin-LL/Reorderable

По лицензии MIT (текст лицензии)

  • AppMetrica SDK (Яндекс): github.com/appmetrica/appmetrica-sdk-android

По лицензиям правообладателей

  • Yandex Mobile Ads SDK вместе с входящими в него компонентами Yandex Varioqub: лицензионное соглашение Yandex Mobile Ads SDK
  • Библиотеки сервисов Google Play (Basement, Base, Tasks, App Set) и библиотека Google Play Install Referrer: лицензионное соглашение Android Software Development Kit
  • Google Play Billing Library (только версия из Google Play): лицензионное соглашение Android Software Development Kit
  • Google Play In-App Review и In-App Updates (обновления только в версии из Google Play): условия Play Core Software Development Kit
  • Иконки Icons8: icons8.com/license
